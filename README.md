# Gifted Delights by Divyanshi

A mobile-first static storefront for a handmade crochet brand.

## Included
- Responsive handmade-focused design
- 12 catalogue products, each with a unique product ID
- Category filters
- LocalStorage shopping basket
- Basket → WhatsApp order message containing IDs, quantities and subtotal
- Custom-order CTA
- About/story, FAQs and footer
- Temporary stock/demo imagery from Unsplash and Pexels

## Before launch
1. Replace `WHATSAPP_NUMBER` in `index.html` with the brand's WhatsApp number, including country code.
2. Replace the temporary stock images with Divyanshi's own product photographs.
3. Replace the Instagram placeholder URL in the footer.
4. Review prices, product names and descriptions.

The site is intentionally dependency-light: one HTML file with CSS and vanilla JavaScript, so it can be deployed directly with GitHub Pages.
